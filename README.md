The Startup Funding Analysis Dashboard (2020–2025) analyzes funding trends, investor activity, and sector performance using Microsoft Power BI. The dashboard presents key metrics such as total funding, total startups, and average funding through interactive visualizations.

The analysis shows strong funding growth after 2022, with Maharashtra emerging as a leading hub. Sectors like FinTech and Artificial Intelligence attract the highest investments, while funding remains concentrated in a few regions.

Overall, the project demonstrates how data visualization tools can convert raw data into meaningful insights, helping users understand trends and make informed decisions.
